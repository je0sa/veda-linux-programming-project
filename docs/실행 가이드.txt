Raspberry Pi 원격 하드웨어 제어 데몬 시스템 - 최종 실행 가이드

본 문서는 한화비전 VEDA 과정 [리눅스 시스템 프로그래밍 심화 실습] 과제인
'Raspberry Pi 원격 장치 제어 데몬 시스템'의 올바른 컴파일, 배포, 
서버 가동 및 클라이언트 연동 순서를 정리한 실행 가이드 파일입니다.

----------------------------------------------------------------------
[0단계] 사전 준비 및 환경 체크
----------------------------------------------------------------------
1. 네트워크 연결 확인
   - 개발 PC (Ubuntu Linux)와 타겟 보드 (Raspberry Pi 4)가 반드시 
     동일한 네트워크망(WiFi 또는 LAN)에 연결되어 있어야 합니다.

2. 배포 스크립트 수정
   - 프로젝트 루트 디렉토리에 있는 'scp.sh' 파일을 열어 본인의 
     라즈베리파이 접속 정보에 맞게 주소를 수정합니다.
     (예시 주소: RPI_IP="100.94.125.69", RPI_USER="jjhword")

3. 타겟 보드 환경
   - 라즈베리파이에 'wiringPi' 및 I2C 통신 환경이 활성화되어 있어야 합니다.

----------------------------------------------------------------------
[1단계] 통합 빌드 및 원격 배포 (Ubuntu Host PC)
----------------------------------------------------------------------
개발 PC(Ubuntu)의 프로젝트 최상위 루트 디렉토리에서 자동화 쉘 스크립트를 실행합니다.

$ ./scp.sh

[동작 매커니즘]
① 마스터 Makefile이 작동하여 client, device, server 폴더를 순회하며 분할 컴파일을 수행합니다.
② 크로스 컴파일러(aarch64-linux-gnu-gcc)를 통해 라즈베리파이 전용 바이너리를 생성합니다.
③ 컴파일이 완료되면 프로젝트 루트의 'bin/' 폴더에 아래 3개의 파일이 생성됩니다.
   - 'bin/client'     (우분투 실행용 텍스트 CLI 클라이언트)
   - 'bin/server'     (라즈베리파이 실행용 TCP 데몬 서버)
   - 'bin/libdevice.so' (라즈베리파이 가동용 하드웨어 제어 공유 라이브러리)
④ 스크립트 내부의 scp 명령어가 가동되어 라즈베리파이의 타겟 디렉토리(~/rpi_project)로 
   'server' 바이너리와 'libdevice.so' 라이브러리를 안전하게 자동 원격 전송합니다.

----------------------------------------------------------------------
[2단계] 데몬 서버 가동 및 로그 감시 (Raspberry Pi Target Board)
----------------------------------------------------------------------
라즈베리파이에 터미널(SSH 등)로 접속하여 전송된 서버를 가동합니다.

1. 라즈베리파이 배포 디렉토리로 이동
   $ cd ~/rpi_project

2. 백그라운드 데몬 서버 실행
   $ ./server
   
   ※ 중요: 'server'는 실행 즉시 Stevens 패턴의 'become_daemon' 함수를 통해 
     부저/스레드/소켓 자원을 완전히 독립시킨 후 스스로 백그라운드 자식 프로세스로 
     전환되며, 터미널 제어권을 사용자에게 즉시 반환(Exit)합니다. 
     따라서 프로세스가 죽은 것이 아니라 정상적으로 백그라운드에 상주한 상태입니다.

3. 커널 로깅 시스템(syslog) 실시간 모니터링 가동
   - 데몬 프로세스는 표준 출력(printf)이 블랙홀(/dev/null)로 리다이렉트되므로, 
     커널 로거를 통해 실시간 작동 상태를 추적해야 합니다.
   
   $ sudo journalctl -f -t ./server

   [정상 작동 시 출력 로그 로그 메시지]
   - "라즈베리파이 백그라운드 원격 제어 서버 데몬화 성공"
   - "[TCP Server] Client 대기 모드"

----------------------------------------------------------------------
[3단계] 원격 제어 클라이언트 실행 (Ubuntu Host PC)
----------------------------------------------------------------------
다시 개발 PC(Ubuntu) 터미널로 돌아와 'bin/' 폴더에 생성된 클라이언트를 실행합니다.

1. 프로젝트 최상위 루트 폴더에서 client 실행 (인자로 라즈베리파이 IP 주소 입력)
   $ ./bin/client 100.94.125.69

2. 연결 성공 프롬프트 확인
   - 정상 연결 시 화면에 '[Connect Success] 라즈베리파이 원격 제어 서버 연결'이 
     점등되며 다중 I/O 멀티플렉싱(`select`) 제어 프롬프트 메뉴판이 활성화됩니다.

----------------------------------------------------------------------
[4단계] 하드웨어 원격 제어
----------------------------------------------------------------------
클라이언트 콘솔에서 1번부터 5번 메뉴를 선택하여 원격 장치를 제어합니다.

[메뉴판 가이드]
- 1: LED 제어 -> HIGH, MID, LOW, OFF, EXIT 입력 가능 (소프트웨어 PWM 연동)
- 2: CDS 조도 센서 -> 임계값(Threshold) 입력 시 현재 조도 실시간 전송 수신 및 LED 자동 점등 제어
- 3: 7-SEGMENT -> 시작 숫자(0~9) 입력 시 카운트다운 가동 (0 도달 시 부저 작동)
- 4: BUZZER -> ON/OFF 제어 (ON 입력 시 학교종 멜로디 재생, OFF 입력 시 volatile 플래그 차단 종료)
- 5: EXIT -> 클라이언트 안전 종료 및 데몬 서버 소켓 자원 반환
